# Brief for a User Story: Remote Closure of an Investment Account

**Task:** Prepare a brief that is enough to write a user story with acceptance criteria for a brokerage feature: closing an individual investment account online, including sending documents to the tax service.
**What I did:** Structured the brief into five parts (role, goal, output format, tone, context), described the 6-step process, and defined what the acceptance criteria must cover: file formats, file size, sending errors, and re-uploading one document without filling in the whole request again.
**Tools:** Word.
**Result:** A brief that sets the audience (developers and Product Owner), the expected format and at least 7 acceptance criteria, and adds one process improvement: a wrong tax certificate no longer forces the client to cancel the request and start over.

Individual work. The brief was written as a prompt for an AI assistant; process details are anonymized. Documents are in Russian.
